MCP 是一个公开标准,让 ChatGPT / Claude 这类聊天应用能安全地调用外部应用——外部应用提供「工具 + 界面」,聊天应用负责对话和模型。下面 5 张模拟图走完一个用户的完整流程:连接 → 唤起 → 全屏 → 读报告 → 改 Persona。
